# 欢迎来到我的知识分享空间

这是一个基于 Next.js 构建的个人知识分享网站。所有文章都使用 Markdown 格式编写，支持丰富的格式和功能。

## 主要特性

### 🔐 安全的访问控制
- 基于邀请码的访问机制
- JWT token 设备绑定
- 无需注册，简单高效

### 📝 简单的内容管理
- 纯 Markdown 文件管理
- Git 即 CMS，版本控制自然集成
- 支持标签分类和搜索

### 🚀 优化的部署体验
- Netlify 一键部署
- 自动构建和发布
- 高性能静态网站

## 如何添加新文章

1. 在 `posts/` 目录下创建新的 `.md` 文件
2. 按照以下格式添加文章头部信息：

```markdown
---
title: "文章标题"
date: "2024-01-01"
excerpt: "文章摘要"
tags: ["标签1", "标签2"]
author: "作者名"
---

# 文章内容开始

这里是文章的正文内容...
```

3. 提交到 Git 仓库，自动部署生效
