## 📋 使用步骤

### 1. 访问登录页面
打开浏览器，访问管理后台登录页面：
```
http://localhost:3003/admin/login
```

### 2. 执行登录操作
1. 在用户名输入框中输入：`admin`
2. 在密码输入框中输入：`admin123`
3. 点击"登录"按钮
4. 系统将自动跳转到管理后台首页

### 3. 管理后台功能
登录成功后，您可以访问以下功能：
- 📊 **仪表板** - 查看系统统计信息
- 📝 **文章管理** - 创建、编辑、删除文章
- 📈 **数据统计** - 查看访问分析
- 🏷️ **标签管理** - 管理文章标签
- 👤 **用户管理** - 管理管理员账户

## 🔧 问题排查

### 常见问题及解决方案

#### 问题1: 无法登录
**症状:** 输入正确密码但仍无法登录
**解决方案:**
1. 点击登录页面的"检查认证状态"按钮
2. 查看控制台日志获取详细信息
3. 尝试点击"清理认证状态"按钮
4. 刷新页面后重新登录

#### 问题2: 页面显示异常
**症状:** 登录页面无法正常显示
**解决方案:**
1. 确保开发服务器正在运行 (端口3003)
2. 清除浏览器缓存: `Ctrl + F5`
3. 检查浏览器控制台是否有JavaScript错误

#### 问题3: 认证状态异常
**症状:** 已登录但显示未登录状态
**解决方案:**
1. 使用登录页面的调试工具
2. 点击"清理认证状态"按钮
3. 重新登录

### 调试工具使用

登录页面集成了强大的调试工具：

#### 检查认证状态
点击"检查认证状态"按钮可以查看：
- 当前Cookie中的认证数据
- localStorage中的认证信息  
- sessionStorage中的认证信息
- 详细的控制台日志

#### 清理认证状态
点击"清理认证状态"按钮可以：
- 清除所有认证相关的Cookie
- 清理localStorage中的认证数据
- 清理sessionStorage中的认证数据
- 重置认证状态

**使用步骤:**
1. 点击"清理认证状态"按钮
2. 等待清理完成提示
3. 手动刷新页面 (`F5`)
4. 重新执行登录操作

## 🔒 安全最佳实践

### 密码安全
1. **修改默认密码** - 首次登录后立即修改
2. **使用强密码** - 包含大小写字母、数字、特殊字符
3. **定期更换密码** - 建议每90天更换一次
4. **不要共享密码** - 保持密码的私密性

### 会话安全
1. **及时登出** - 使用完毕后登出系统
2. **不要在公共设备保存密码** - 避免在公共电脑上记住密码
3. **定期清理浏览器数据** - 清除Cookie和缓存
4. **监控登录日志** - 注意异常登录活动

## 🛠️ 管理员操作

### 修改密码
1. 登录管理后台
2. 进入"用户管理"页面
3. 找到admin用户，点击"编辑"
4. 输入新密码并确认
5. 保存更改

### 创建新管理员
1. 进入"用户管理"页面
2. 点击"新建用户"
3. 填写用户信息和密码
4. 设置适当的权限级别
5. 保存用户信息

### 系统监控

- 用户登录日志
- 系统错误日志  
- 数据库连接状态
- 磁盘空间使用情况
